# Pogxium Lab

Independent research in quantum computing and its implications for security.

Pogxium Lab favours small, verifiable experiments on real quantum hardware: circuits built without knowledge of the answer, analyses fixed and time-stamped before each run, deliberately broken "false witness" circuits as controls, and every line of code and raw count made public.
